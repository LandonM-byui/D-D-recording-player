# Increment: D&D Recording Player Website shell

User and task:
A visitor wants to understand the hiking guide and navigate its main sections
using a small screen, a keyboard, or both.
A visitor wants to listen to all of the D&D recordings we have made. Those in my friend group can add in our recordings.

Context and constraints:
Create a working shell page for a D&D listening service. I would like it to be one page. For the color scheme, and style, please use a picture of the 3.5 Players Handbook for D&D as a reference. I would like the title of the page to be: The Lad's Listening Stones.

Acceptance criteria:
- The page has a header with the page name, main introductory
  content, and a footer.
- The page has a selector to determine which campaign to choose from. Populate it with Princes and Eberron for now.
- Another selector determines which session to play. These should have the sessions from the chosen campaign. Make 4 random sessions for each campaign. Session number, name, participating characters, and participating players are all needed.
- The page also has an audio player for the session.
- Bellow the audio session. Present all of the information about the chosen session in a clean, readable way. 
- At 320, 768, and 1280 CSS pixels wide, text remains readable and navigation
  does not cause page-level horizontal scrolling.
- At 200% browser zoom, content and links remain available and usable.

Outside this increment:
Connection to the Supabase, filtering, and visual polish.
